In brief

This free kit is for people who sell to businesses and want to prospect without blasting cold email lists. The idea is to look for signals—public events that suggest a company may need your help now, such as an open role, a product launch, or a new executive—and then find the decision-maker and write a message that mentions that signal. Claude Code does the heavy lifting with Clay (a company and contact data platform) and gives you a spreadsheet to review. You need Claude Code, a Clay account (there’s a free plan and a trial), and an afternoon to fill in your business context.

The problem and the idea

Cold lists wear everyone out. A signal opens a conversation.

Traditional prospecting buys a list, sends the same message to everyone, and hopes for the best. Almost no one replies, the domain lands in spam, and the brand gets a reputation for being annoying.

🧊 The problem

Cold lists without context, generic AI-written messages, dozens of tabs and tools, and emails that go straight to spam.

📡 The idea

Prospect based on a signal: first find who has a reason to talk now, then find the right person and talk about that reason.

🧠 How the work is split

Clay handles the data problem (companies, jobs, emails). Claude Code handles the tools: you ask in plain language, and it does the work. You review and decide.

How it works

The 7 steps

Each step filters the one before it. The costly credits (for people and emails) are spent only on companies that passed the signal check.

1 · ICP→ 2 · Hiring signal→ 3 · Research agent→ 4 · Decision-maker→ 5 · Waterfall→ 6 · Message→ 7 · Review + send
1

ICP: the company list

ICP means ideal customer profile. You define the industry, size, and country; Clay returns companies that fit.

2

Hiring signal

Clay monitors open roles with titles that matter to you. An AI role, for example, can point to an AI project getting started.

3

Research agent

An AI agent column reads the company site, blog, and news and answers with a link: has the company launched a new product in recent months?

4

Find decision-makers only when there’s a signal

The people search has a run condition: it runs only for companies with a signal. This is where you save credits.

5

Email enrichment waterfall

Several email providers run in sequence; the waterfall stops at the first valid result. Then the email is verified.

6

Message with context

Claude Code reads your business files and writes a subject and body that mention the company’s signal, with a simple question and an opt-out.

7

Human review + sequencer

You review the spreadsheet and only then import it into a sequencer, sending from a warmed-up domain with a low daily volume.

Terms used in this guide

TermMeaning
TerminalYour computer’s command window (Terminal on Mac and Linux; PowerShell on Windows). Claude Code runs there.
Plugin, marketplace, skillA plugin teaches Claude Code to use a tool; a marketplace is the catalog it comes from; a skill is a ready-made set of steps inside it (e.g., clay:setup).
Credit and actionClay’s units: credits pay for provider data (email, company, person); actions pay for running steps.
SignalA public event that gives you a reason to talk now (an open role, launch, new executive, investment).
WaterfallSeveral data providers queried in sequence until one finds the data.
CTAThe call to action at the end of the message. Here, always low-key: a simple question.
Opt-outThe option to stop: a line explaining how to stop receiving messages.
SequencerA tool that sends campaign emails gradually and sends reminders (follow-ups). Clay has one; separate tools are also available.
Warmed-up secondary domainAn address similar to your company’s (e.g., contact-yourcompany.com) used only for prospecting. It starts by sending a small number of emails and gradually increases, helping email providers trust it. If something goes wrong, your main domain stays protected.

Step-by-step guide

From zero to a reviewed spreadsheet

Commands starting with / are entered inside Claude Code. Enter the others in the terminal.

1

Download the kit and open Claude Code in the folder 🧠 you

The kit becomes your prospecting project folder. Its CLAUDE.md file tells Claude Code how to behave (don’t spend credits without asking, run 10 rows first, never send anything).

git clone https://github.com/inematds/prospeccao-por-sinais.git
cp -r prospeccao-por-sinais/kit ~/minha-prospeccao
cd ~/minha-prospeccao
claude

No git? Download the .zip, unzip it, copy the kit folder wherever you like, open a terminal in that folder, and type claude.

2

Install the official Clay plugin 🧠 you

Inside Claude Code, add the marketplace and install the plugin. Then ask it to run the setup skill, which installs the clay command line and signs you in.

/plugin marketplace add clay-run/agent-plugins
/plugin install clay@clay-plugins
# then, in English:
Run the clay:setup skill and sign me in to Clay.

Using Codex? The equivalent is codex plugin marketplace add clay-run/agent-plugins, then install clay in Plugins.

3

Fill in your business context 🧠 you

Open the 6 templates in contexto/ (profile, offer, cases, proof, FAQ, voice). Use contexto/exemplo/ (a fictional company) as a reference. The agent must not claim anything that isn’t in provas.md. The example is for a software company; replace the ICP, roles, and signals with ones from your market (for a local business, see the Brazil section).

# ask Claude Code for help
Read contexto/exemplo/ and interview me to fill in contexto/ with my company’s information.
4

Define your signals 🧠 you + 🤖 agent

Edit sinais.yaml: each signal has a validity window in days and a weight. To get help figuring out which signals matter in your market, you can use a public skill that generates signals:

# optional, in the terminal
npx skills add clay-run/clay-skill-creator --skill customer-signal-generator
5

Test with 10 rows 🤖 agent · ⚙️ Clay

Before running any batch, run workflow steps 1 and 2 on 10 companies. Check how many have a signal and how many people have a verified email. Prompts for each step are in prompts/passo-a-passo.md (in Portuguese).

Follow Step 1 and Step 2 of prompts/passo-a-passo.md on 10 companies.
Show me the results and estimated cost before running more.
6

Run /goal with a clear finish line 🤖 agent · ⚙️ Clay

/goal tells Claude Code to keep going until a verifiable condition is met: N leads, no blank columns, verified email, subject and body mentioning the signal, a low-key CTA, and a final CSV. The full prompt is in prompts/goal-prospeccao.md (in Portuguese).

/goal I want 25 new signal-based prospecting leads, ready for human review.
... (copy the rest of prompts/goal-prospeccao.md)

Even inside /goal, CLAUDE.md tells the agent to stop and ask you for a “go-ahead” before each step that spends credits. If your version of Claude Code doesn’t have /goal, run the prompts in prompts/passo-a-passo.md (in Portuguese) one at a time; the result is the same.

7

Review the spreadsheet 🧠 you

Open saida/leads-AAAA-MM-DD.csv. The columns are listed in colunas-csv.md (in Portuguese). Start with rows where revisar = sim, read each message, and check the signal link.

# main columns
empresa, decisor, cargo, email, email_status, sinal, resumo_sinal,
link_fonte_sinal, gancho, assunto, corpo, revisar
8

Import into a sequencer and send gradually 🧠 you · ⚙️ sequencer

A sequencer gradually sends the campaign and its reminders (see Terms used in this guide). In Clay: import data, CSV, new table, then create a campaign using that table as the list; you can also buy sending accounts there. Send from a warmed-up secondary domain, with a low daily volume, and increase it gradually. Anyone who asks to opt out goes into supressao.csv (in Portuguese).

# practical rule
warmed-up secondary domain → low daily volume → increase gradually
spam rate below 0.3% (Gmail sender requirement)

Saving credits

The biggest money saver: a run condition

Finding people and emails costs the most. So that search runs only where it makes sense.

StepRuns onWhy
Company list (ICP)all companies that match the filterit’s the starting point; test with 10 first
Hiring signal and research agentall companies on the listfinds who has a reason to talk now
Decision-maker searchonly companies with a signalcompanies without a signal don’t spend credits on people
Email waterfallonly decision-makers foundstops at the first valid email
Mobile phoneonly if you asknot available on free/trial

“Company with a signal” has one definition, the same in CLAUDE.md, the prompts, and sinais.yaml: the sum of the weights of active signals (within their validity window) is 30 or more. Change that number in sinais.yaml if you want to be more or less strict.

Brazil

Using this in Brazil: LGPD and data coverage

The workflow works here, with two things to keep in mind.

⚖️ LGPD

B2B prospecting often relies on legitimate interest. In practice:

  • contact relevant to the person’s role;
  • clear identification of who is writing;
  • an easy opt-out in every message;
  • always respect the suppression list;
  • no sensitive personal data;
  • keep the source of every data point.

The kit includes checklist-lgpd.md (in Portuguese). This is not legal advice; check with your legal team. References: Law 13,709/2018 and ANPD, Brazil’s data protection authority.

🗺️ Data coverage varies by country

Data sources have different coverage in each country and industry. So:

  • always test 10 rows and see how many return a verified email;
  • if the data source is weak, ask the agent to look on the company’s website (contact or team page);
  • for a small local business (clinic, store, office), use Google Maps and the website as sources for your list.
Common mistakes

What goes wrong (and how to avoid it)

Almost all problems come from skipping one of the rules in CLAUDE.md.

✗ Run the whole table right away

You can use up the month’s credits with one bad setup. Always start with 10 rows.

✗ Find decision-makers at every company

This is the biggest waste. Use the run condition: only for companies with a signal.

✗ Empty context

Without a profile, cases, and proof, AI writes a generic message. Fill in contexto/ first.

✗ Signal without a source or past its date

Mentioning a job that has already closed sounds careless. Require a link and respect each signal’s validity window.

✗ Send from your main domain

If it lands in spam, your company’s email reputation takes the hit too. Use a warmed-up secondary domain.

✗ High volume on day one

Send a few emails a day, increase gradually, and keep the spam rate below 0.3%.
