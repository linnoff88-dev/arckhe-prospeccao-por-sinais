En resumen

Este kit gratuito es para quienes venden a empresas y quieren prospectar sin enviar correos a listas frías. La idea es buscar señales, es decir, hechos públicos que muestran que una empresa podría necesitarte ahora (una vacante abierta, el lanzamiento de un producto, un nuevo director), y solo entonces encontrar a la persona que toma la decisión y escribir un mensaje que mencione esa señal. Claude Code hace el trabajo pesado con Clay (una plataforma de datos de empresas y contactos) y te entrega una hoja de cálculo para que la revises. Necesitas Claude Code, una cuenta de Clay (hay un plan gratis y una prueba) y una tarde para completar el contexto de tu negocio.

El problema y la idea

Las listas frías cansan a todos. Una señal abre la conversación.

La prospección habitual compra una lista, envía el mismo texto a todos y cruza los dedos. Casi nadie responde, el dominio acaba en spam y la marca se gana fama de molesta.

🧊 El problema

Lista fría sin contexto, mensaje genérico creado por IA, decenas de pestañas y herramientas, y un correo que llega directo a spam.

📡 La idea

Prospectar a partir de señales: primero descubrir quién tiene un motivo para conversar ahora, luego encontrar a la persona adecuada y hablar de ese motivo.

🧠 Cómo se divide el trabajo

Clay resuelve el problema de los datos (empresas, vacantes, correos). Claude Code resuelve el problema de las herramientas: tú le pides algo en español y él lo ejecuta. Tú revisas y decides.

Cómo funciona

Los 7 pasos del flujo

Cada paso filtra el anterior. Los créditos más costosos (persona, correo) solo se gastan en las empresas que dieron la señal.

1 · ICP→ 2 · Señal de contratación→ 3 · Agente de investigación→ 4 · Persona que decide→ 5 · Cascada→ 6 · Mensaje→ 7 · Revisión + envío
1

ICP: la lista de empresas

ICP es el perfil del cliente ideal. Defines el sector, el tamaño y el país; Clay devuelve las empresas que encajan.

2

Señal de contratación

Clay monitorea las vacantes abiertas con los cargos que te interesan. Una vacante de IA, por ejemplo, indica que podría estar empezando un proyecto de IA.

3

Agente de investigación

Una columna con un agente de IA lee el sitio web, el blog y las noticias, y responde con un enlace: ¿la empresa lanzó un producto nuevo en los últimos meses?

4

Busca a la persona que decide solo cuando hay una señal

La búsqueda de personas tiene una condición de ejecución: solo se ejecuta en empresas con una señal. Así ahorras créditos.

5

Enriquecimiento en cascada

Se consultan varios proveedores de correo en secuencia; la cascada se detiene en el primer resultado válido. Después se verifica el correo.

6

Mensaje con contexto

Claude Code lee los archivos de tu negocio y redacta el asunto y el cuerpo mencionando la señal de esa empresa, con una pregunta sencilla y la opción de dejar de recibir mensajes.

7

Revisión humana + herramienta de secuencias

Revisas la hoja de cálculo y solo entonces la importas a la herramienta de secuencias, para enviar desde un dominio con buena reputación y pocos correos al día.

Requisitos previos

Qué necesitas antes de empezar

No necesitas programar. Escribirás algunos comandos en la terminal (la ventana de comandos de la computadora).

Claude Code

El asistente de Anthropic que funciona en la terminal. Necesitas una suscripción paga de Claude (consulta los planes en claude.com/pricing). El plugin de Clay requiere la versión 2.1.91 o posterior. Instálalo y comprueba la versión:

# instalar (Mac/Linux)
curl -fsSL https://claude.ai/install.sh | bash
# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
# o, si ya tienes Node.js
npm install -g @anthropic-ai/claude-code
# comprobar la versión
claude --version

Documentación oficial: Claude Code.

Guía de uso · paso a paso

De cero a una hoja de cálculo revisada

Los comandos que empiezan con / se escriben dentro de Claude Code. Los demás, en la terminal.

1

Descarga el kit y abre Claude Code en la carpeta 🧠 tú

El kit será la carpeta de tu proyecto de prospección. Su archivo CLAUDE.md ya le indica a Claude Code cómo comportarse (no gastar créditos sin pedirte permiso, ejecutar 10 filas primero, nunca enviar nada).

git clone https://github.com/inematds/prospeccao-por-sinais.git
cp -r prospeccao-por-sinais/kit ~/mi-prospeccion
cd ~/mi-prospeccion
claude

Si no tienes git: descarga el archivo .zip, descomprímelo, copia la carpeta kit donde quieras, abre la terminal en esa carpeta y escribe claude.

2

Instala el plugin oficial de Clay 🧠 tú

Dentro de Claude Code, agrega el marketplace e instala el plugin. Luego pídele que ejecute la skill de configuración, que instala la línea de comandos clay e inicia sesión.

/plugin marketplace add clay-run/agent-plugins
/plugin install clay@clay-plugins
# después, en español:
Ejecuta la skill clay:setup e inicia sesión en Clay por mí.

¿Usas Codex? El equivalente es codex plugin marketplace add clay-run/agent-plugins e instalar clay en Plugins.

3

Completa el contexto del negocio 🧠 tú

Abre los 6 modelos de contexto/ (perfil, oferta, casos, pruebas, preguntas frecuentes, tono de voz) (en portugués). Usa la carpeta contexto/exemplo/ (en portugués; contiene una empresa ficticia) como referencia. El agente no puede afirmar nada que no esté en provas.md (en portugués). El ejemplo es para una empresa de software; cambia el ICP, los cargos y las señales según tu mercado (para un negocio local, consulta la sección Brasil).

# pide ayuda al propio Claude Code
Lee contexto/exemplo/ y entrevístame para completar contexto/ con los datos de mi empresa.
4

Define tus señales 🧠 tú + 🤖 agente

Edita sinais.yaml (en portugués): cada señal tiene un plazo de validez en días y un peso. Si quieres ayuda para descubrir qué señales importan en tu mercado, hay una skill pública para generar señales:

# opcional, en la terminal
npx skills add clay-run/clay-skill-creator --skill customer-signal-generator
5

Prueba con 10 filas 🤖 agente · ⚙️ Clay

Antes de ejecutar cualquier lote, sigue los pasos 1 y 2 del flujo con 10 empresas. Revisa cuántas tienen una señal y cuántas personas tendrían un correo verificado. Los prompts para cada paso están en prompts/passo-a-passo.md (en portugués).

Sigue los pasos 1 y 2 de prompts/passo-a-passo.md en 10 empresas.
Muéstrame el resultado y el costo estimado antes de ejecutar más.
6

Ejecuta /goal con un objetivo verificable 🤖 agente · ⚙️ Clay

/goal hace que Claude Code continúe hasta que se cumpla una condición verificable: N leads, columnas completas, correo verificado, asunto y cuerpo que mencionen la señal, una CTA sencilla y un CSV final. El prompt completo está en prompts/goal-prospeccao.md (en portugués).

/goal Quiero 25 leads nuevos para prospectar a partir de señales, listos para revisión humana.
... (copia el resto de prompts/goal-prospeccao.md)

Incluso dentro de /goal, el CLAUDE.md le indica al agente que se detenga y te pida permiso antes de cada paso que consuma créditos. Si tu versión de Claude Code no incluye /goal, ejecuta los prompts de prompts/passo-a-passo.md (en portugués) uno por uno: obtendrás el mismo resultado.

7

Revisa la hoja de cálculo 🧠 tú

Abre saida/leads-AAAA-MM-DD.csv. Las columnas están en colunas-csv.md (en portugués). Empieza por las filas con revisar = sim, lee cada mensaje y comprueba el enlace de la señal.

# columnas principales
empresa, decisor, cargo, email, email_status, sinal, resumo_sinal,
link_fonte_sinal, gancho, assunto, corpo, revisar
8

Importa los datos a la herramienta de secuencias y envía poco a poco 🧠 tú · ⚙️ herramienta de secuencias

La herramienta de secuencias envía la campaña poco a poco y manda recordatorios (consulta Palabras que aparecen en la guía). En Clay: importa los datos desde un CSV en una tabla nueva y luego crea la campaña usando esa tabla como lista; allí también puedes comprar cuentas de envío. Envía desde un dominio secundario con buena reputación, con pocos correos al día, y aumenta el volumen poco a poco. Quienes pidan dejar de recibir mensajes se agregan a supressao.csv (en portugués).

# regla práctica
dominio secundario con buena reputación → pocos correos al día → aumentar poco a poco
tasa de spam inferior al 0,3% (regla de Gmail para remitentes)

Gmail: directrices para remitentes de correo (tasa de spam inferior al 0,3% y aumento gradual del volumen).

Prueba de 14 días

Plan Launch

💡 Créditos que se devuelven

En la cascada, los proveedores habituales de correo y celular devuelven el crédito si no encuentran el dato. Además, la cascada se detiene al encontrar el primer resultado válido.

📵 Al principio, deja el celular fuera

La búsqueda de celulares no está disponible en el plan gratis ni durante la prueba. Empieza solo con correos.

Fuentes: documentación pública de Clay (planes y cobros; cómo crear una cascada de datos).

Ahorro de créditos

La regla que más ahorra: la condición de ejecución

Lo que más cuesta es buscar personas y correos. Por eso, esa búsqueda solo se ejecuta cuando vale la pena.

EtapaSe ejecuta enPor qué
Lista de empresas (ICP)todas las del filtroes la base; prueba con 10 antes
Señal de contratación y agente de investigacióntodas las empresas de la listasepara a quienes tienen un motivo para conversar ahora
Búsqueda de la persona que decidesolo empresas con una señaluna empresa sin señal no gasta créditos en buscar personas
Correo en cascadasolo las personas encontradasse detiene al encontrar el primer correo válido

«Empresa con señal» tiene una sola definición, igual en CLAUDE.md, en los prompts y en sinais.yaml (en portugués): la suma de los pesos de las señales activas (dentro del plazo de validez) es de 30 o más. Cambia ese número en sinais.yaml si quieres ser más o menos estricto.

Brasil

Uso en Brasil: LGPD y cobertura de datos

El flujo funciona aquí, con dos precauciones.

⚖️ LGPD brasileña

La prospección B2B suele basarse en el interés legítimo. En la práctica:

  • contacto relevante para el cargo de la persona;
  • identificación clara de quien escribe;
  • opción sencilla para dejar de recibir mensajes en cada correo;
  • respeto permanente por la lista de supresión;
  • ningún dato personal sensible;
  • registro del origen de cada dato.

El kit incluye checklist-lgpd.md (en portugués). No es una opinión jurídica: consulta con tu equipo legal. Referencias: Ley brasileña 13.709/2018 y ANPD, la autoridad brasileña de protección de datos.

🗺️ La cobertura de datos varía según el país

Las bases de datos tienen distinta cobertura según el país y el sector. Por eso:

  • prueba siempre 10 filas y revisa cuántas tienen un correo verificado;
  • si la base es limitada, pídele al agente que busque en el sitio web de la empresa (página de contacto, equipo);
  • para una pequeña empresa local (clínica, tienda, oficina), usa Google Maps y el sitio web como fuentes para crear la lista.
Errores comunes

Qué puede salir mal (y cómo evitarlo)

Casi todos los problemas surgen por saltarse una de las reglas de CLAUDE.md.

✗ Ejecutar toda la tabla de inmediato

Consume los créditos del mes con una configuración incorrecta. Empieza siempre con 10 filas.

✗ Buscar a quien decide en todas las empresas

Es el mayor desperdicio. Usa la condición de ejecución: solo en empresas con señales.

✗ Contexto vacío

Sin perfil, casos y pruebas, la IA redacta un mensaje genérico. Completa contexto/ (en portugués) antes de empezar.

✗ Señal sin fuente o vencida

Mencionar una vacante que ya cerró parece descuidado. Exige un enlace y respeta el plazo de cada señal.

✗ Enviar desde el dominio principal

Si los correos llegan a spam, también afecta el correo de la empresa. Usa un dominio secundario con buena reputación.

✗ Enviar muchos correos el primer día

Envía pocos al día, aumenta el volumen gradualmente y mantén la tasa de spam por debajo del 0,3%.
